# SuperMimic 算法审查与 toy 实验

审查对象：当前仓库实现和 `logs/lafan1-rtx5060-eager/config.json`。本报告描述代码事实、严格条件下的数学结论与玩具实验，不把玩具结果当作 G1 训练结果。

## 已确认的实现

- 策略接收 10 帧参考特征与 10 帧本体历史；当前训练 `anchor_obs=false`。本体观测包含相对关节位置、关节速度、机身角速度、投影重力和上一步动作，缺少全局平移与显式根部线速度。参考特征也没有目标的绝对水平位置。
- 奖励包括锚点全局位置和姿态、身体位置/姿态/速度、动作变化和关节限位。相对锚点观测是已有的可选输入，启用后会改变策略输入维度和 checkpoint 兼容性；实际部署需要能获得参考与机器人的相对位姿。
- 当前世界模型训练窗口为 8 步，策略想象时域为 32 步。单模型状态误差指标无法直接提供策略梯度误差或真实策略表现的保证；8 与 32 不一致本身也不构成错误。
- 环境对动作加入标准差 0.1 的高斯噪声，世界模型用执行动作拟合，想象时使用干净策略动作。前者可以是收集数据的探索设计；评估环境本身关闭动作噪声，因此是否在想象中加噪取决于目标任务。
- 想象窗口在片段末尾固定最后参考帧；实际环境将片段结束作为 timeout。timeout 需要考虑正确的截断与 bootstrap，不能简单等同于失败终止。
- 动作变化惩罚已存在；没有明确的足部接触/滑动奖励。是否增加这些项应以实测问题和消融为依据。32 维潜变量不足、固定相位不佳、采样不均与单模型被利用都属于待验证假设。

## 数学分析

### 1. 信息不足的严格反例

设单步系统 `x' = x + a`，目标为 0，初始 `x ~ Uniform[-1,1]`。假设观测与 x 无关，则任意确定性策略只能输出常数 `a`。其期望损失为

`E[(x+a)^2] = E[x^2] + 2a E[x] + a^2 = 1/3 + a^2 >= 1/3`。

如果观测到 x，取 `a=-x`，损失为 0。随机策略若其随机性与 x 独立，同样无法低于 1/3。

在本仓库中，固定参考与其它状态，将机器人全局水平位置整体平移，`analytic_observation` 不变；`anchor_relative_obs` 改变。连续 10 帧都施加同样平移时，历史本体观测也保持不变。这严格证明该输入无法区分这种平移，但**不能单凭此证明**真实 G1 分布里增加锚点观测必然提高回报：可达状态分布、奖励取舍、传感误差与训练优化都会影响结果。

### 2. 世界模型误差的上界

固定同一动作序列，真实动力学 `F` 和模型 `F_hat` 在所有相关状态和动作上满足 `||F_hat(s,a)-F(s,a)|| <= eps`，且 `F` 对状态是 L-Lipschitz。相同初态下，令 `d_t=||s_hat_t-s_t||`，则

`d_(t+1) <= ||F_hat(s_hat_t,a_t)-F(s_hat_t,a_t)|| + ||F(s_hat_t,a_t)-F(s_t,a_t)|| <= eps + L d_t`。

由归纳法得 `d_t <= eps * sum_(i=0)^(t-1) L^i`。当 `L=1`，`d_t <= t eps`。如果每步奖励对状态是 `L_r`-Lipschitz，且只考虑相同动作序列与固定长度的累计奖励，则累计误差不超过

`L_r eps * sum_(t=0)^(H-1) sum_(i=0)^(t-1) L^i`。

当 `L=1`，上界为 `L_r eps H(H-1)/2`。闭环策略需要对闭环映射和奖励重新建立 Lipschitz 条件；摔倒的硬终止、分布外状态和不满足统一误差上界时，这个界不能直接套用。它是上界而非预测：32 步不一定比 8 步差。

小状态预测误差也不自动保证反向传播的梯度准确。例如 `f(x)=0`、`f_hat(x)=eps sin(x/eps^2)`，两者函数值误差最多 eps，但在 x=0 处导数差为 `1/eps`。因此仅看状态 MSE 无法证明策略梯度可靠。

### 3. 动作噪声和非线性

令执行动作为 `a+eta`，`E[eta]=0`，`Var(eta)=sigma^2`。若动力学某分量是 `f(a)=a^2`，则 `E[f(a+eta)]=a^2+sigma^2`，与 `f(a)=a^2` 不同。若 `f(a)=a`，二者期望相同。故噪声遗漏可能带来非线性偏差，但并非必然影响当前目标或一定需要在想象中加噪。

## 可检验的后续消融

1. 固定数据划分、训练预算及种子，比较原策略和相对锚点观测；按未见完整动作报告根部误差、完成率、摔倒率，同时测加入估计噪声后的表现。
2. 在同一批真实 replay 窗口上比较真实与世界模型 1/8/16/32 步误差；分别看接触切换和失稳附近的误差，并比较想象回报与真实回报。现有 8 步训练指标不能代替这些测量。
3. 分别比较 H=8/16/32；控制总采样和优化预算，报告多种子结果。若发现模型被利用，再评估多模型分歧惩罚或其他保守更新。它们会增加计算和显存开销。
4. 单独测量片段末尾起点的真实占比与想象回报，明确片段结束后的任务定义，再决定采用截断、正确 bootstrap 或末帧保持。
5. 如果足部滑动、动作抖动或不同时间尺度确实突出，分别做足部奖励、时序编码与相位控制消融。改变相位会改变轨迹执行时间，应同时衡量动作跟踪和时间误差。
